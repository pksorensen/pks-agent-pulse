# pks-agent-pulse

Pulse belongs to the Kanariefugl family and is a runtime product. It owns periodic active measurements and report-ready evidence across arbitrary owner-scoped components. `web` is the first component.

It composes with Agentics Fabrik for scheduled work, `pks-agentics-runner` for workload identity, `pks-cli` for distribution, and `pks-agent-ops` when active outside-in measurements need to be correlated with inside-out telemetry.
